Statut du projet

Un projet « en cours » passe automatiquement en privé (par praticité), mais vous pouvez quand même le remettre en public juste en dessous si vous le souhaitez.

Visibilité

Dans les deux cas, le projet apparaît dans « Nos projets ». Seuls les projets publics apparaissent aussi dans « Explorer ».

Aperçu

Collez un lien direct vers une image ou une vidéo, ou un lien YouTube (ex : un lien Imgur, un fichier hébergé sur Google Drive/Dropbox en partage public, ou youtube.com/watch?v=…). Le type est détecté automatiquement.

Accès au projet

Lien vers le projet (GitHub, Drive, site web…).

Compte

Créez un compte pour ajouter des projets sans ressaisir votre nom à chaque fois : c'est le pseudo de votre compte qui est utilisé automatiquement.
